WHAT THE MODEL SEES:

Input: Last 30 seconds of I/O pressure readings
  ┌─────────────────────────────────────────┐
  │ [0.5, 1.2, 2.1, 3.5, 15.2, 25.1, ...]  │
  │  └─────────── PSI over time ─────────┘  │
  └─────────────────────────────────────────┘

The model thinks:
  "Hmm, it's slowly going up: 0.5 → 1.2 → 2.1 (normal)
   But then JUMP to 15.2 → 25.1 (sudden spike!)
   
   Next reading will probably be SPIKE-level PSI
   My prediction: 18% PSI → This is a SPIKE! 🚨"

Output: Prediction for NEXT reading
  ┌──────────────────┐
  │ Spike? YES/NO    │
  │ Confidence: 90%  │
  └──────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│ WHAT METRICS MEAN (REAL EXAMPLE)                                            │
└─────────────────────────────────────────────────────────────────────────────┘

Imagine the model made 100 predictions:

WHAT ACTUALLY HAPPENED:
├─ Real spikes occurred: 50 times
└─ No spike (normal): 50 times

WHAT MODEL PREDICTED:
├─ Predicted spike: 60 times
│  ├─ Correct (real spike happened): 45 times ✓ (TRUE POSITIVES)
│  └─ Wrong (no spike happened): 15 times ✗ (FALSE POSITIVES)
│
└─ Predicted no spike: 40 times
   ├─ Correct (no spike): 35 times ✓ (TRUE NEGATIVES)
   └─ Wrong (spike happened): 5 times ✗ (FALSE NEGATIVES)


CALCULATING METRICS:

PRECISION = "When we say SPIKE, how often are we right?"
  = TRUE POSITIVES / (TRUE POSITIVES + FALSE POSITIVES)
  = 45 / (45 + 15)
  = 45 / 60
  = 75%
  
  Translation: "3 out of 4 spike alerts are real"

RECALL = "When spikes actually happen, how often do we catch them?"
  = TRUE POSITIVES / (TRUE POSITIVES + FALSE NEGATIVES)
  = 45 / (45 + 5)
  = 45 / 50
  = 90%
  
  Translation: "We catch 9 out of 10 real spikes"

F1-SCORE = Balance of precision and recall
  = ~82%
  
  Translation: "Overall model quality is good"
