## Correct Interpretation

### Calm Bins (NaN Correlation)

In calm bins:
- Signal = 0.0 everywhere (constant, zero variance)
- Correlation coefficient requires variation in both variables
- NaN is the correct result, not evidence of independence
- **Conclusion**: Test is "not evaluable" on calm bins, not "passed"

### Stress Bins (0.9996–0.9998 Correlation)

| Dataset | Correlation |
|---------|-------------|
| Train | 0.9996 |
| Test | 0.9998 |
| Validation | 0.9953 |

**This is not independence.** This is co-generation.

### Lag Profile (Flat, Not Peaked)

- Lag −60s: corr = 0.9869
- Lag −40s: corr = 0.9925
- Lag −20s: corr = 0.9960
- Lag 0s: corr = 0.9999
- Lag +20s: corr = 0.9960
- Lag +40s: corr = 0.9923
- Lag +60s: corr = 0.9868

**Real reactive signal**: Would show peak at positive lag (signal lags outcome by consistent time)

**This lag profile**: Flat plateau at 0.99–1.0, slight roll-off at extremes

**Conclusion**: Not a lagged observation. Co-generated from same source.

## Critical Finding: The Data is Synthetic

### Evidence

1. **Correlation = 0.9996 in stress bins** (not independent)
2. **Lag scan is flat** (no peak at any lag; not reactive with measurable lag)
3. **Source code**: `generate_server_data.py` line 95
   ```python
   latency_ms = 45 + 28*load + 75*psi_some_avg10 + noise
   ```
   Both `latency_ms` and `psi_some_avg10` depend on `load`.

### What This Means

- Signal and latency are **co-generated by the same synthetic model**
- They are not independent measurements
- Correlation = 0.9996 is **not** a property of real systems
- Any threshold found by analyzing this data validates the generator, not the system
